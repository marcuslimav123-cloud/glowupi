# Glow Upi

## Overview
Glow Upi is a multi-tenant SaaS platform designed for beauty salon and studio management. It offers a comprehensive suite of tools for appointment scheduling, client management, financial tracking, marketing, and loyalty programs. The platform aims to be a leading solution in the beauty industry, focusing on enhancing operational efficiency and client engagement for beauty professionals.

## System Architecture
The project is a full-stack monorepo built with `pnpm workspaces`. The frontend utilizes `React`, `Vite`, `TailwindCSS`, `shadcn/ui`, and `Recharts`. The backend is developed using `Express 5` and `PostgreSQL` with `Drizzle ORM`. `TypeScript 5.9` is used consistently across the entire monorepo.

**UI/UX Decisions:**
The design embodies a "luxury clinic aesthetic" with a color palette of warm gold, cream, and off-white. Typography includes `Inter` for body text and `DM Serif Display` for headings, complemented by subtle borders and `fafafa` backgrounds for an Apple-inspired look. Dark mode is fully supported through semantic Tailwind tokens. PWA icons include `maskable` purpose for Android.

**Technical Implementations:**
- **Authentication:** Session-based authentication using cookies, supporting Google Sign-In and a multi-level access control system (owner, manager, collaborator, client, super admin). New user registration is exclusively handled via Google Sign-In.
- **API:** OpenAPI-documented endpoints prefixed with `/api`, with client code generated by Orval.
- **Database:** `PostgreSQL` managed by `Drizzle ORM`, architected for multi-tenancy.
- **Stripe Integration:** Manages subscriptions, product synchronization, and webhooks for various pricing tiers.
- **Reporting & Exports:** Supports data export functionalities to `XLSX` and `PDF` formats.
- **Monorepo Structure:** Organized into `artifacts` (api-server, barberpro), `lib` (shared code), and `scripts`.
- **Multi-tenancy:** Ensures each salon operates in an isolated environment.
- **Subscription Management:** Features configurable trial periods, professional limits per plan, differentiated billing periods, and full data preservation upon plan changes. Includes one-time trial links for super admins.
- **Appointment & Schedule Management:** Offers a visual agenda, professional schedules, peak hours analysis, and server-side double booking prevention. Includes a public booking portal with accessibility features and WhatsApp cancellation.
- **Client & Product Management:** Provides detailed client profiles, product inventory, and movement history, including Excel/CSV client import with smart header detection.
- **Financial & Reporting:** Handles commission calculations, split payments, discounts, financial accounts, daily cash register, and analytical reports, including coupon usage tracking.
- **Marketing & Loyalty:** Features loyalty programs, an in-app messaging system, discount coupons, automated reminders, and client grouping.
- **Configurable Parameters:** Tenant-scoped business rules configurable across 8 categories.
- **Notification System:** In-app notification bar with unread counts and pop-up dropdowns, alongside web push notifications via the `web-push` library.
- **Granular Access Profiles:** Menu-level permissions based on user roles.
- **Mobile Navigation:** Fixed bottom tab navigation for mobile and a comprehensive mobile menu page.
- **Multi-location Support:** Branch/multi-location capability for specific plans.
- **Admin Panel:** A dedicated super admin interface for platform management, including trial link generation and service import.
- **Email:** Round-robin email sending via Brevo with Gmail SMTP fallback for transactional emails and invites.
- **Team Invite Flow:** Owners can invite team members with specific roles.
- **Direct Sales Page (PDVD):** Streamlined checkout and onboarding, bypassing free trials, with a promotional landing page for Meta Ads traffic.
- **Object Storage & Image Upload:** GCS-backed object storage via Replit App Storage for logos and photos, utilizing presigned URLs.
- **Mobile App – Glow Upi Pro:** Expo SDK mobile app with modular navigation, covering all web functionalities with a focus on parity. Includes Apple Sign-In, Apple Push Notifications, App Tracking Transparency, RevenueCat IAP integration, and account deletion functionality adhering to Apple guidelines and LGPD.
- **Professional Anamnese Module:** A clinical anamnesis system with a form builder, client prontuário, before/after photo gallery, digital consent forms with signature pad, health alerts, and procedure history.
- **Onboarding Wizard:** A 4-step guided wizard for initial business setup.
- **LGPD Consent Tracking:** Server-side consent logging, first-login dialog for privacy policy and terms of use acceptance, and an admin panel for viewing consent logs.
- **Message Bank & Human Mode:** Categorized template bank with CRUD and rendering capabilities for variables. Features a "Human Mode" flag to intercept automated messages, routing them to a suggested message queue for manual review and sending.

## Push Notifications — Operação
- **Web Push (VAPID):** requer secrets `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` e opcionalmente `VAPID_SUBJECT` (default `mailto:marcuslimav123@gmail.com`). Gere o par com `npx web-push generate-vapid-keys`. Sem essas chaves o backend loga warn no boot e desabilita web push silenciosamente; status visível em `GET /api/health/push` (requer role `dono`).
- **Expo Push:** sem credenciais necessárias para o app público; tokens mortos são desativados via tickets imediatos e via polling de receipts.
- **Channels Android:** `default` (HIGH) para avisos gerais, `lembretes-agendamentos` (MAX) para lembretes/agendamentos.
- **Health endpoint:** `GET /api/health/push` reporta estado VAPID, contagem de tokens ativos por plataforma e estado do DB.

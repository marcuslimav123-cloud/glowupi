# Glow Upi

## Overview
Glow Upi is a multi-tenant SaaS platform for beauty salon and studio management. It provides comprehensive features for appointment scheduling, client management, financial tracking, marketing, and loyalty programs for beauty professionals. The platform aims to be a leading management tool in the beauty industry, enhancing operational efficiency and client engagement.

## System Architecture
The project is a full-stack monorepo using `pnpm workspaces`. The frontend uses `React`, `Vite`, `TailwindCSS`, `shadcn/ui`, and `Recharts`. The backend is built with `Express 5` and `PostgreSQL` with `Drizzle ORM`. `TypeScript 5.9` is used across the entire monorepo.

**UI/UX Decisions:**
The design follows a "luxury clinic aesthetic" with warm gold, cream, and off-white colors. It uses `Inter` for body text and `DM Serif Display` for headings, featuring subtle borders and `fafafa` backgrounds for an Apple-inspired look. Dark mode is supported using semantic Tailwind tokens.

**Technical Implementations:**
- **Authentication:** Session-based with cookies, supporting Google Sign-In and multi-level access control.
- **API:** OpenAPI-documented endpoints with `/api` prefix, client code generated by Orval.
- **Database:** `PostgreSQL` with `Drizzle ORM`, structured for multi-tenancy.
- **Stripe Integration:** Manages subscriptions, product syncing, and webhooks for various pricing tiers.
- **Reporting & Exports:** Data export to `XLSX` and `PDF`.
- **Monorepo Structure:** Divided into `artifacts` (api-server, barberpro), `lib` (shared code), and `scripts`.
- **Multi-tenancy:** Each salon operates in an isolated environment.
- **Subscription Management:** Configurable trial periods, professional limits per plan, and billing options.
- **Appointment & Schedule Management:** Visual agenda, professional schedules, peak hours analysis, and double booking prevention.
- **Client & Product Management:** Detailed client profiles and product inventory.
- **Financial & Reporting:** Commission calculations, split payments, discounts, financial accounts, daily cash register, and analytical reports.
- **Cupom de Indicação / Relatório de Cupons:** Each comanda may bind a `cupom_id` and `cupom_desconto` (set at checkout — see `artifacts/api-server/src/routes/agendamentos.ts`). The cupom usage counter is incremented atomically inside the same transaction, replacing the legacy standalone `POST /cupons/:id/usar` endpoint (still present, returns `deprecated:true`). New endpoints (dono/gerente only): `GET /api/barbearias/:id/cupons/relatorio?inicio&fim` (ranking by receita líquida; computes usos, receitaBruta, receitaLiquida, descontoTotal, ticketMedio) and `GET /api/barbearias/:id/cupons/:cupomId/comandas?inicio&fim` (drill-down). UI: `/relatorios/cupons` (page `pages/relatorios/RelatorioCupons.tsx`) with period filter, Top 5 highlight, ranked table with click-to-drill, and Excel/CSV export. The cadastro page `/cadastros/cupons` shows lifetime "Receita gerada" / "Desconto concedido" per cupom and a "Relatório" link button. No backfill of historical comandas — only data captured after this change appears in the report.
- **Marketing & Loyalty:** Loyalty programs, message system, discount coupons, automated reminders, and client groups.
- **Public Booking Portal:** Allows clients to schedule appointments publicly, with accessibility features and equipment capacity checks.
- **Configuração de Parâmetros:** Tenant-scoped business rules configuration across 8 categories.
- **Barra de Notificações:** In-app notification system with unread counts and pop-up dropdowns.
- **Perfis de Acesso Granulares:** Menu-level permissions based on user roles.
- **Mobile Navigation:** Fixed bottom tab navigation for mobile and a comprehensive mobile menu page.
- **Filiais (Múltiplas Unidades):** Branch/multi-location support for specific plans.
- **Admin Panel:** Separate super admin interface for platform management, including trial link generation.
- **One-Time Trial Links:** Super admin generated unique, single-use trial links with atomic claim and automated data cleanup.
- **Email:** Round-robin email sending via Brevo with Gmail SMTP fallback for transactional emails and invites.
- **Team Invite Flow:** Owners can invite team members with specific roles.
- **Google-Only Registration:** New user registration is exclusively via Google Sign-In.
- **Página de Venda Direta (PDVD):** Direct sales page with streamlined checkout and onboarding.
- **Object Storage & Image Upload:** GCS-backed object storage via Replit App Storage for logos and photos using presigned URLs.
- **Marketing Video:** Professional 30-second cinematic marketing video built with React + Framer Motion.
- **Mobile App – Glow Upi Pro:** Expo mobile app for owners and professionals with dashboards and push notifications.
- **Push Notifications:** Uses Expo Push API for mobile and `web-push` library for browser notifications.
- **AppBeleza Clone Overhaul:** Expanded functionality including daily cash register, service categories, suppliers, anamnesis forms, and more.
- **Performance & Bug Fixes:** Code splitting with `React.lazy` + `Suspense`, optimistic CRUD updates, improved error handling, and WhatsApp clickable links.
- **Excel Client Import:** Bulk import clients from Excel/CSV with smart header detection, preview, and batch processing.
- **Admin: Manage Super Admins:** Super admin management page with status toggle and audit logging.
- **Admin: Excel Service Import:** Super admin can bulk-create services for tenants via .xlsx upload with template download, preview, and confirmation steps.
- **Professional Anamnese Module:** Clinical anamnesis system with form builder, client prontuário, before/after photo gallery, digital consent forms with signature pad, health alerts, and procedure history.
- **Onboarding Wizard (Rewritten):** 4-step guided wizard for business info, services, hours, and team, with a celebration screen and PWA prompt.
- **Promotional Landing Page (Fundadoras):** Women-focused landing page for Meta Ads traffic with specific pricing and a sales funnel structure.
- **PWA Icons for Android:** Dynamic manifest includes `maskable` purpose icons for Android.
- **LGPD Consent Tracking:** Server-side consent logging, first-login dialog for privacy policy and terms of use acceptance, and an admin page for consent logs.

## External Dependencies
- **Stripe:** Payment processing, subscription management.
- **PostgreSQL:** Primary database.
- **Google Sign-In API:** User authentication.
- **Brevo (Sendinblue):** Primary email provider for transactional emails and contact management.
- **web-push:** Library for sending web push notifications.
- **ViaCEP:** Address auto-fill service.
- **Recharts:** Data visualization library.
- **Orval:** API client code generation tool.
- **jspdf & jspdf-autotable:** PDF generation libraries.
- **xlsx:** Excel file generation library.
